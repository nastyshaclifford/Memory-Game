Memory Game (Игра "Запоминалка")

Милая браузерная игра на внимательность и память: кликай по карточкам и находи пары одинаковых эмодзи!

## Технологии
- HTML5
- CSS3 (адаптивная верстка, flex/grid, переменные, стилизация элементов управления)
- JavaScript (DOM, обработчики событий, логика игры)
- Git/GitHub

## Функциональность
- Пользователь сам выбирает ширину и высоту игрового поля
- Карточки рандомно перемешиваются
- Подсчет количества ходов
- Таймер с момента начала игры
- Победа фиксируется при открытии всех пар
- Адаптивный дизайн


## 🛠️ Установка
1. Клонируй репозиторий
2. Открой `index.html` в браузере
